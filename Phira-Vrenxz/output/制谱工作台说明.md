# 制谱工作台（v1.3.4）

在 Phira-Vrenxz 里内置的 RPE 谱面工作台，对标 PhiraPro / RPE 制谱器的「时间轴 + 判定线 + 音符」工作流。

## 打开

1. 运行 `dist\Phira-Vrenxz-main-1.3.4-workbench.exe`
2. 在主界面按 **F10**（只在主界面生效，避免在游戏中途误触）
3. 列表里点一条本地谱面即可进入编辑；「返回」按钮回列表，左上角返回键回列表后再按一次退到主界面

列表来源：`data/charts/custom` 下所有含 `judgeLineList` 的 RPE json。PEC 谱（`formatVersion` 那种）不会列出来，工作台暂不支持。

## 操作

| 操作 | 说明 |
| --- | --- |
| 点击网格空白 | 在该判定线的落点处新增音符（时间 + 横向位置同时落） |
| 点住音符拖动 | 横向拖动改拍位、纵向拖动改横向位置；长条尾巴随动 |
| 左侧判定线列表 | 切换当前正在编辑的判定线（右侧数字是音符数） |
| 底栏 蓝键/长条/黄键/绿键 | 新建音符类型 |
| 底栏 线上/线下 | 新建音符的 above（1/2） |
| 底栏 1/4 等 | 吸附网格，点一下在 1/4 → 1/8 → 1/16 之间循环 |
| 底栏 撤销 / Ctrl+Z | 回退上一步（20 步） |
| 底栏 保存 / Ctrl+S | 写回原 RPE json；首次保存自动留一份 `<文件名>.json.bak` |
| 滚轮 | 左右平移时间轴；`Ctrl+滚轮` 或 `+` `-` 缩放 |
| `←` `→` | 移动拍游标（橙色竖线） |
| `Del` / `Backspace` | 删除选中音符 |
| `Home` | 回到 0 拍 |

时间轴横轴是拍位（按 `BPMList` 换算，标题栏同时显示秒数），纵轴是音符的 `positionX`（±675 映射到网格上下边界外 1.15 倍，方便摆到屏幕外）。

## 保存格式

只改 `judgeLineList[i].notes[j]` 里的 `startTime` / `endTime` / `positionX` / `type` / `above`，其余字段（事件层、`blockAreaList`、`META`、`effects`）原样保留，所以用 RPE 打开还能正常二次编辑。

新建音符会补齐 RPE 需要的字段：`alpha/size/speed/isFake/judgeArea/tint/visibleTime/yOffset`。

## 这一版没做（下一轮）

- 判定线自身的事件层编辑（moveX/moveY/rotate/alpha/speed/scale 关键帧）、新建/删除判定线
- 图层（layerId）、图片/文字（extended 事件）、噪域（blockAreaList）的图形化编辑
- 谱面内实时试听 / 播放预览（现在只能存盘后用游戏或 `--render` 看效果）
- 多步重做（redo）、批量框选、复制粘贴
- PEC 谱面读写
