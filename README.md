## 🛠 Build from Source

### Prerequisites
- Rust (nightly recommended)
- Android SDK & NDK (for Android build)

### Build Commands
```bash
# Desktop (Windows/Linux)
cargo run -p Phira-Vrenxz-main

# Android APK
cargo apk build -p Phira-Vrenxz
